# Project Name
Detects and lables butterflies in the Nymphalidae family

## Features
- Detects
- Lables
- Adjustable confidence levels

## Requirements
- Python 3.11
- pip install gradio opencv-python ultralytics numpy Pillow tensorflow

## Installation
Clone the repository:
git clone https://github.com/fieldsoftansy/gradio-web-app.git

## Usage
python app.py
